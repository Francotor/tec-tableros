# Biblioteca de medidores / empalmes (datos de prueba)

Esta carpeta trae SOLO datos mínimos (una caja y una pieza) para probar que el editor carga el catálogo según el tipo de proyecto.
Mismo formato de fichas que `public/biblioteca/`: `catalogo.json`, `gabinetes.json`, `componentes/*.svg` y `gabinetes/*.svg`.
Si el catálogo real trae riel o canaleta, agregar también `lineales.js` (rielSVG, canaletaSVG), igual que en `public/biblioteca/`.
